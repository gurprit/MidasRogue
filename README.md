# Midas Rogue v0.3

A contrarian, lawful AI entrepreneurship trial with a £0 incremental spending limit and a 30-day initial window. First customer revenue milestone £1, stretch goal £100 net cash profit before tax. No earnings are guaranteed.

## Self-funding milestone
The first recurring target is £100 monthly net profit before tax. This triggers an affordability review, not an automatic Pro upgrade. Confirm the actual UK price and available limits, and retain at least two months of the full subscription cost in earned, uncommitted cash after other costs and appropriate reserves. The owner approves any purchase. See AGENTS.md for the full policy and state/SELF-FUNDING.md for the tracking template.

## Resume the experiment
1. Select this repository in a Codex Cloud environment, or clone it into a dedicated local directory.
2. Use your existing Codex allowance when available, with normal sandboxing and approval controls enabled. Do not connect financial accounts or provide API keys.
3. Paste: `Read AGENTS.md, state/STATUS.md, research/SCORING.md and missions/005-r.md. Execute Mission 005-R within the charter, prepare one small experiment and stop for my explicit launch approval.`
4. Review the launch-ready materials and proposed experiment in a draft pull request before approving further work. Never interpret general approval as authorisation to pay or publish.

This is a starter workspace, not an installed scheduler, API service, payment system or fully autonomous business. The owner starts each session and controls external actions. Instructions alone are not hard technical spending controls; keep billing, permissions and tool approvals restricted. Monitor allowance and stop when exhausted. A private repository is recommended before storing commercial research or financial records. Never commit credentials, personal data or unredacted receipts.

Keep records suitable for business bookkeeping. UK owners should check applicable tax, benefits and self-employment reporting requirements. No separate legal entity is created by this project.
