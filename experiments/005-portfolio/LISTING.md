# Milni · Product Hunt submission draft

**Name** · Milni

**Tagline** · One private space for your Indian wedding weekend

**Website** · https://milne.app/

**Description**

Milni gives Indian wedding organisers one private space for a multi-day celebration. Bring the ceremony schedule, travel details, menus and live updates together so guests can find the latest plan without digging through messages. Milni is built around events and traditions that can vary from one family to the next.

**First maker comment**

I built Milni around a problem that comes up when families organise several events across a wedding weekend: the schedule, coach times and last-minute updates can end up in different chats.

If you're currently planning an Indian wedding or help organise them, what detail is hardest to keep current for guests? If Milni could replace the separate itinerary and travel messages for one wedding, would you pay **£19 once** for that wedding space?
